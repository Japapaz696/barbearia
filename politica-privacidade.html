Nosso Compromisso

A Barbado's Barbearia respeita sua privacidade e está comprometida em proteger seus dados pessoais em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei 13.709/2018). Esta política explica como coletamos, usamos e protegemos suas informações.

1. Dados Coletados

Dados de Identificação

  • Nome completo
  • Telefone/WhatsApp
  • E-mail (opcional)
  • Data de nascimento (opcional, para bônus de aniversário)

Dados de Agendamento

  • Histórico de serviços realizados
  • Datas e horários de agendamentos
  • Barbeiro preferido
  • Observações de preferência

Dados Técnicos

  • Endereço IP (para segurança)
  • Dados de navegação (cookies essenciais)
  • Dispositivo e navegador

2. Finalidade do Tratamento

Utilizamos seus dados para:

  • Agendamento de serviços: Confirmar, lembrar e gerenciar seus horários
  • Comunicação: Enviar confirmações, lembretes e avisos via WhatsApp/e-mail
  • Fidelidade: Controlar pontos, cupons e benefícios do programa
  • Melhoria: Avaliações para melhorar nossos serviços
  • Segurança: Prevenir fraudes e garantir integridade do sistema
  • Obrigatórios: Cumprir obrigações legais e fiscais

3. Compartilhamento de Dados

Não vendemos seus dados. Compartilhamos apenas quando necessário:

  • WhatsApp Business API: Para envio de notificações (Meta Platforms)
  • Provedor de hospedagem: Para manter o site online
  • Autoridades legais: Quando exigido por lei ou ordem judicial
  • Processadores de pagamento: Apenas se houver pagamento online futuro

4. Seus Direitos (LGPD - Art. 18)

Você tem direito a:

  • Confirmação: Saber se tratamos seus dados
  • Acesso: Obter cópia dos seus dados
  • Correção: Atualizar dados incompletos ou incorretos
  • Anonimização/Bloqueio: De dados desnecessários ou excessivos
  • Exclusão: Pedir eliminação dos dados (exceto obrigações legais)
  • Portabilidade: Receber seus dados em formato estruturado
  • Informação: Saber com quem compartilhamos
  • Revogação: Cancelar consentimento a qualquer momento
  • Oposição: Recusar tratamento baseado em legítimo interesse
Para exercer seus direitos:
Solicitar via WhatsApp

5. Segurança dos Dados

  • Criptografia em trânsito (HTTPS/TLS 1.3)
  • Armazenamento local no navegador (localStorage) para protótipo
  • Em produção: banco de dados criptografado com acesso restrito
  • Acesso apenas por pessoal autorizado
  • Logs de acesso para auditoria
  • Backup seguro e plano de resposta a incidentes

⚠️ Nota: Este é um protótipo. Em produção, implementaremos backend seguro com LGPD completa.

6. Retenção de Dados

  • Dados de agendamento: 5 anos (obrigação fiscal)
  • Dados de cadastro: enquanto a conta estiver ativa
  • Dados de marketing: até revogação do consentimento
  • Logs de acesso: 6 meses
  • Dados anonimizados para estatísticas: indeterminado

7. Cookies

Utilizamos apenas cookies essenciais:

  • Sessão: Manter você logado
  • Preferências: Tema claro/escuro, configurações
  • Agendamento: Dados temporários do orçamento
  • NÃO usamos: Cookies de rastreamento, analytics de terceiros, publicidade

8. Dados de Menores

Não coletamos intencionalmente dados de menores de 18 anos sem consentimento dos responsáveis. Se você é menor de idade, peça aos seus pais ou responsáveis para agendar por você.

9. Transferência Internacional

Seus dados podem ser processados pela Meta (WhatsApp) que possui servidores internacionais. A Meta possui certificações de adequação (Standard Contractual Clauses) para transferência de dados pessoais do Brasil.
